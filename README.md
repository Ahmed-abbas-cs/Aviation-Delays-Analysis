# US Flights Performance and Delays Analysis

## Project Overview
This project analyzes the performance of US airlines and identifies the root causes of flight delays. By processing operational flight data, the project extracts actionable insights to help understand which airlines and airports face the most significant logistical challenges.

## Tools and Technologies Used
1. Python (Pandas): For data cleaning, handling missing values, and sampling a large dataset down to 50,000 records for optimized performance.
2. SQL (SQLite): To query the cleaned data, aggregate delay minutes by cause, and rank airlines and airports based on performance metrics.
3. Tableau: For building an interactive and visually appealing dashboard to present the findings to stakeholders.

## Key Insights
1. Late aircraft arrivals serve as the primary root cause of overall flight delays, significantly outweighing weather or security issues.
2. Specific regional carriers exhibited higher average delay times compared to major national airlines.
3. High traffic volumes at major hubs strongly correlate with an increase in average departure delays, highlighting areas needing operational improvements.
